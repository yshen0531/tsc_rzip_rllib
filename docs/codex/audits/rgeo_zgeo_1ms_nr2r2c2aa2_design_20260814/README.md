# C2aA2 prospective candidate-selection audit

`selection.json` is a zero-new-TSC, zero-fit descriptive reduction of three
already consumed NR2R1 **development** records. It freezes the candidate set
before C2aA2 implementation or outcome. No calibration or invalid holdout
record was used.

The four early opposition values are same-time differences against the
tracked C1a q0 comparator. They select three minus-sign directions whose first
observed event window was positive at all four states. This does not establish
persistent authority, identify a plant Jacobian, or qualify a model. The real
C2aA2 discriminator retains the unchanged C2aA1 persistent-authority gates.

The three source-record hashes are recorded for provenance. Their full raw
records remain outside this tracked audit because they are existing consumed
development evidence, not fixtures or a new dataset.
