# Fixed-1000 D3 support-gated discrete candidate-value data design

## Decision record

G3 is final as a clean scientific FAIL.  Its block2 coordinate was a valid
exact Card15 input but produced only `0.0108--0.0124 mm` h4/h8 response and
`0.0216--0.0248 mm` signed separation.  It is retained as a negative
development label; it is not deleted to manufacture a rank-four PASS.

The useful result is narrower: even, odd and block4 have strong, unequal,
phase-dependent task-plane effects.  D3 therefore abandons the claim that
all inputs form one uniformly authoritative linear basis.  It measures an
explicit discrete library with support/refusal semantics and a real matched
no-action continuation.  This is a material semantic change, not a fifth
code or an adjacent amplitude/phase/duration repair.

## Frozen campaign

The canonical source is fixed `1000ms`; fixed-1100 evidence is forbidden.
Every rollout has 48 issues and states 1000--1048.  At issue 8, one cumulative
exact-return conditioner is applied: block4 plus or block4 minus.  At issue
24, the matched candidate is one of:

`baseline`, `even+`, `even-`, `odd+`, `odd-`, `block4+`, `block4-`.

Each non-baseline macro follows levels
`1,2,3,4,4,4,4,4,3,2,1,0`, where one level is the prospectively fixed
`0.14 A` requested single-turn increment and every target is independently
quantized to exact Card15.  The cumulative return is exact q0; it is not a
claim of plant-state recovery.  The matrix is 14 primary development rows
plus two zero-fit integrity replays, exactly 16 resets / 768 advances, with
no retry and no result-dependent arm addition.

## Gates and claim boundary

All hard interface, paired-boundary, Ip, limiter, absolute-current, exact
Card15, issued/readback slew, raw and replay gates are fail-closed.  Scientific
readiness is evaluated separately in each conditioner history.  At h4 or h8:

- at least two of the three signed axes must have separation >= 0.10 mm;
- the six measured signed candidates must span the task plane with maximum
  angular gap <= 180 degrees, weakest-best projection >= 0.04 mm, rank two
  and condition <= 20;
- h4/h8 absolute paired Ip response must remain <= 400 A and h12/h16 return
  tails must remain inside 3 mm / 400 A.

No gate requires every candidate to be strong: weak and adverse candidates
are legitimate labels.  A single transient cannot substitute for h4/h8.

PASS means only that one direct, support-gated candidate-value model may use
the fourteen primary rows together with already prospectively fit-eligible
fixed-1000 development data.  It does not authorize calibration, blind
opening, Authority, Recourse, feedback, MPC, expert data or online learning.
FAIL closes this discrete library; there is no fifth code, adjacent amplitude,
phase, duration, or third-model ladder.

After D3 PASS the remaining route is bounded: one direct candidate-value
model, one fresh calibration and unopened whole-history blind test, then
Authority and Recourse as independent gates before any feedback sentinel.
