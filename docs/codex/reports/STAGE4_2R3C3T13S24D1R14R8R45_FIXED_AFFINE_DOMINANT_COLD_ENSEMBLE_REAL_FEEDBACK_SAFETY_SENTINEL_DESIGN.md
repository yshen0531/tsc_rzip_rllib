completed prefix and measured currents. Start a new search from that measured
state, propagate candidate suffixes only through the fixed ensemble and full
tube, execute only the first action of a safe supported robust-formal plan,
then discard the suffix. Planned states never become measurements.

non-finite value, unsupported state, unsupported transition, empty safe

pair/history label, source identity/outcome, future action, hidden simulator
state, wire/vessel current, and future R17 output remain forbidden controller
inputs. The independent audit must replay every selected first action from
