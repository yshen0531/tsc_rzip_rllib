R51R3 proved that all 13 actual one-step transport/exact-return/hold candidates
repair `0/10` failed R8R7 baseline contexts. Every failed context had a small
positive best-margin gain, `0.0001221--0.0034286`, but its best formal margin
remained negative. The short-pulse family is insufficient; this does not test
whether keeping the same safe transport current for several completed states
provides useful authority.

R51R4 asks:

```text
Can a bounded sustained dwell at one already authenticated transport current,
followed by exact causal return to the stored q0 center, repair any of the ten
failed contexts without weakening action or current safety?
```

The candidate subset is development-selected from the five identities that
won at least one failed R51R3 context:

```text
d0m  d1p  d2m  d3p  u1p50
```

They include one authenticated nonzero direction on each of the four q axes
plus one mixed direction. They are not an independent holdout or causal
selector.
