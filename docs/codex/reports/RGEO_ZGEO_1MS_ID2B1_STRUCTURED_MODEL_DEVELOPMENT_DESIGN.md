# R_geo/Z_geo 1 ms ID-2B1 structured model development design

Date: 2026-08-15 Asia/Shanghai

Identity: `rgeo-zgeo-1ms-id2b1-structured-model-development-v1`

## Decision and evidence boundary

ID-2B0 completed without TSC, model fitting or holdout access.  Its primary
and independent audits agree exactly and found no exact complete-causal-prefix
collision.  It therefore supports a limited model comparison over the three
ID-2A development contexts, but not a context-robustness, position-dependence,
uncertainty-tube or controller claim.

ID-2B1 fits only the 39 unique ID-2A development cells.  The three critical
replays remain integrity evidence and do not receive extra training weight.
Every sibling trajectory from one causal context remains in the same
leave-one-context-out fold.  Calibration, holdout and all older probe data are
forbidden.  The stage performs zero TSC and zero plant advances.

## Prediction semantics

At every prediction origin, current same-step paired-boundary `R_geo/Z_geo`,
same-step `Ip` and actual 14-coil current are exact observations.  All causal
states and controller-owned actions since 1100 ms are available.  A planner
may supply future candidate issued Card15 actions; future true R/Z/Ip and
future actual-current readback are unknown and forbidden.

The first model is a direct finite-horizon rolling model, not an unconstrained
free-running ARX.  It is re-centred on truth at each real 1 ms cycle.  Its
future-action memory is generated by fixed real poles strictly inside the
unit circle.  It never feeds a predicted state back through an unconstrained
learned transition matrix.  This provides bounded finite-horizon memory but
is not yet a general nonlinear state-space or robust world model.

## Candidates

The frozen comparison contains persistence, damped last velocity, an
action-blind causal-history ridge model, and three action-conditioned stable
exponential-memory ridge models:

1. signed future command memory;
2. signed plus even command memory;
3. signed/even memory with a small fixed set of interactions with the causal
   R/Z/Ip innovation and issued-action history.

All action-conditioned models use actual 14-dimensional q0-centred issued
targets.  `probe_virtual_action` is only an auxiliary two-coordinate future
feature; it cannot erase the p03/p04 arrival history encoded in the real
Card15 prefix.  The fixed poles are `0.25, 0.65, 0.9, 0.98`.  Ridge strengths
and feature sets are frozen; there is no seed or hyperparameter search.
GRU/TCN residuals are deliberately absent.  A neural residual becomes worth
testing only after a structured action-conditioned center passes every fold.

## Evaluation and gates

Absolute predictions alone are insufficient because natural state-10 to
state-32 motion is about 11--16 mm while measured action response is only
0.015--0.848 mm.  Each candidate is therefore evaluated in two ways:

- absolute R/Z/Ip error at rolling origins and horizons;
- evaluator-only paired response: predicted action minus predicted matched
  baseline versus measured action minus measured matched baseline.

Absolute evaluation uses the frozen rolling origins and sparse horizons.
Paired response uses the complete dense state-10-to-state-11--32 curve so a
one-ms action-age event cannot disappear between sparse evaluation horizons.

The matched future baseline is never a predictor feature.  Signal arms have
at least 0.05 mm measured peak response.  Every complete context fold must
meet the frozen absolute caps, paired scaled-error caps, peak-vector direction
fraction and at least 10% paired-response improvement over the action-blind
model.  Selection first minimizes worst-fold paired error, then absolute
error.  A failure is a model/support result, not a TSC, controller or global
plant-authority failure.

## Routes

- Input or source mismatch:
  `ONE_MS_ID2B1_INPUT_OR_DATA_INTEGRITY_FAIL_NO_MODEL_CLAIM`.
- No action-conditioned candidate passes all three complete context folds:
  `ONE_MS_ID2B1_NO_CONTEXT_ROBUST_ACTION_MODEL_TARGETED_DATA_REQUIRED`.
  This stops model escalation and requires a prospective matched-history or
  position/context data discriminator.
- A structured candidate passes:
  `ONE_MS_ID2B1_STABLE_LIFTED_MODEL_PASS_FRESH_CALIBRATION_REQUIRED`.
  This authorizes only a separately frozen fresh calibration design; it does
  not authorize controller/MPC, uncertainty tubes, recovery, transport,
  online adaptation, neural residuals or new TSC under this identity.
