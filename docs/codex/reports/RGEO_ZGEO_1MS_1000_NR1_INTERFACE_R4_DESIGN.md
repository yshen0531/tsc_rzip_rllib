# Fixed-1000 NR1 interface R4

R3R2 qualifies the semantic restart root and authorizes only this fresh
interface stage. R4 uses the r0 reconstructed payload fixed by SHA-256 and
runs the unchanged six-prefix/four-step NR1 matrix.

Issued slew is always checked between active Card15 commands. Because the
saved source actual current is offset from the active command, the first
source-to-successor actual-current delta is descriptive and is isolated by a
matched hold. Probe effect is probe-state1 minus matched-hold-state1; every
component must have the requested sign. Actual-current slew remains a hard
gate from state1 onward. All state, Card15, return, replay and safety gates are
unchanged. PASS qualifies only the one-ms interface, not a model or control.
