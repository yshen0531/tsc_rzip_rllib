# R_geo/Z_geo 1 ms ID-2Z9 late-root branch utility/support design

Date: 2026-08-19

## 1. Purpose and route boundary

ID-2Z8 is final as
`ONE_MS_ID2Z8_SMALL_MODEL_FAIL_TARGETED_DATA_OR_BASIS_REVIEW`. Its two
bounded candidates predicted response direction well, but three independent
decision contexts were insufficient for the R-error and action-ranking
gates. Increasing recurrent capacity is forbidden.

ID-2Z9 is one new simulator-development identity that combines the two
allowed next questions instead of creating separate micro-stages:

1. does the unchanged B/F/H macro grammar still provide material measured
   terminal utility after the selected state-57 decision; and
2. can it supply exactly two additional complete causal contexts for one
   final five-context comparison of the same ID-2Z8 model classes?

It is not a controller, recovery policy, safety tube, hold, waypoint or
calibration/holdout campaign.

## 2. Frozen source and matrix

The sole parent is the independently audited ID-2Z7 critical replay of the
selected `f4 -> b2f2 -> f2b2` prefix. Every new branch starts from the
canonical 1100-ms source and exactly replays the selected prefix. No snapshot
or arbitrary-state restart is used.

Two sequential decision roots are frozen:

```text
round D  decision state 61  issues 61--64
round E  decision state 65  issues 65--68
common observation endpoint state 77
terminal evaluation states 72--77
```

At each root the five siblings are unchanged:

```text
hold4  HHHH
b4     BBBB
f4     FFFF
b2f2   BBFF
f2b2   FFBB
```

After the four issues, each branch holds its attained exact Card15 target
through issue 76. The selected round-D parent is committed before round E is
constructed. One final zero-fit replay reproduces the full selected five-
macro sequence. All rejected siblings are observations from separate
canonical-source branches, never future observations on the main path.

## 4. Exact interface and envelopes

The ID-2Z7 contracts remain unchanged:

- exact/noiseless same-step paired-boundary R_geo/Z_geo and Ip before issue;
- complete takeover-era causal observation/action history;
- future successor and future actual current forbidden;
- exact absolute Card15 targets and issue `k` to state `k+1`;
- per-coil requested/readback slew at most 0.3 A, with exact 0.3 allowed;
- no runner clipping, no software queue and no unrecorded cleanup action;
- exact live prefix, actual-current, 48-wire diagnostic, boundary, Ip,
  runtime, solver, limiter and abnormal-state gates;
- run root fixed to `<new-output>/rollouts` before runner construction.

The three meanings remain separate:

```text
terminal capture set       25 mm distance / 0.1 m/s / 5% source Ip
development preissue shell 35 mm per R/Z axis / 7.5% source Ip
hard envelope              50 mm per R/Z axis / 10% source Ip
```

Post-successor empirical trips remain 2 mm R, 2 mm Z and 150 A Ip. They are
development stops, not pre-action tubes or recovery guarantees. Only the
existing enumerated safe-stop reasons allow proceeding to the next sibling;
all other failures stop the campaign.

## 5. Selection, utility and stop rules

Each round uses the unchanged capture-first terminal selector. A non-hold arm
is eligible only if it captures or improves the six-state worst normalized
terminal score by at least `0.02` relative to that round's matched hold.

Scientific PASS requires all of:

1. both five-sibling matrices complete with a selected non-hold arm;
2. the selected final score improves the round-D matched-hold score by at
   least `0.05`, unless it captures;
3. the final selected sequence replays exactly;
4. all ten development-weight windows are complete; and
5. independent full-raw audit passes.

PASS authorizes only one separately frozen comparison of the same two ID-2Z8
model classes over five whole-context folds. It does not authorize changing
features, gates or capacity after seeing ID-2Z9.

If either round has no eligible non-hold arm, final utility is below `0.05`,
or the complete-window gate fails, this B/F/H grammar closes. The next route
is a bounded action-basis/authority redesign, not another manual depth,
larger network or post-hoc threshold change. Interface, prefix, runtime or
raw failures remain separate non-scientific failures.

## 6. Final-goal boundary

The final goal remains safe causal one-ms approximate two-axis waypoint/path
control from the fixed 1100-ms takeover, later including bidirectional
repeated R_mid crossing with continuous belief. Even an ID-2Z9 PASS would be
only source-local teacher/data evidence. Capture replay, Recourse-L1, fresh
calibration and whole-history holdout remain later independent AND gates.
