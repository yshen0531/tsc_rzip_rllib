## 1. Question and scientific boundary

R8R11 proved that a direction-zero 1.5x target held for two plant intervals
was safe in 96/96 authentic trajectories but repaired none of ten failed
R8R7 baselines. Its best measured margin improvements were positive but small.
The frozen route requires a genuinely asymmetric or multi-direction causal
sequence rather than another duration or amplitude adjustment under R8R11.

R8R12 asks one new finite measured-authority question:

```text
Does a one-sided, cumulative, exact-Card15 staircase in canonical direction 2,
with each new level constructed causally from current readback and then held
to the next decision, repair at least one failed R8R7 baseline while preserving
all hard action, current, restart, causality, and integrity gates?
```

R8R12 is a fixed-policy authority and safety sentinel. It is not a causal
selector, fitted model, general MPC, robustness qualification, long-hold test,
Gate A, expert-data campaign, BC, DAgger, or RL stage. Its retrospective held
oracle is evaluator-only and unavailable to the controller. Every R8R12
trajectory is permanently forbidden from expert and learning datasets.

## 5. Causal cumulative staircase contract

Every rollout uses a fresh controller and fresh TSC process, authentic restart,
and the exact inherited physical action/trace prefix through task step 9. The
future R17 controller is never executed.

At decision steps `[10,14,18,22]`, construct a new exact Card15 target by
adding canonical direction-2 sign `+1` to the current measured coil-current
center. The resulting target is stored in controller memory. At every
intermediate task step, causally reconstruct the action required to hold that
same stored target from current readback:

```text
task step 10     issue level 1 from current measured center
task 11..13      refresh exact stored level-1 target
task step 14     issue level 2 from current measured center
task 15..17      refresh exact stored level-2 target
task step 18     issue level 3 from current measured center
task 19..21      refresh exact stored level-3 target
task step 22     issue level 4 from current measured center
task 23..end     refresh exact stored level-4 target through state 35/37
```

The sequence is intentionally one-sided and non-zero-net. There is no final
return to the original center and therefore no potentially large accumulated
cancellation. Each new level and each refresh is an independently constructed
absolute exact target action from current readback; no open-loop normalized
action is replayed.

The controller may use only the fixed schedule/direction/sign/scale, current
and past visible observations, current measured coil currents, allowed numeric
target, causal clock, and its own stored target. Pair/history/target ID,
partition, source outcome, baseline future, source future action/current,
wire/vessel current, future measurement, and post-advance telemetry are
forbidden.

