## 3. Experiment design and causal checkpoint

The matrix remained the frozen R17/R1 finite grid:

```text
2 targets x 3 delay settings x 3 slew scales = 18 cases
checkpoint elapsed time = 200 ms
normal/strong slew: arrive by 250 ms, evaluate through 350 ms
weak slew 0.9: arrive by 270 ms, evaluate through 370 ms
```

Each controller checkpoint contains only causal information available
through checkpoint step 20:

- measurement/observer history;
- integral state;
- previous correction;
- pending physical delay queue;
- trusted calibration token and modeled delay/slew;
- controller phase;
- source and code fingerprints.

The checkpoint contains zero future actions and zero future measurements.
After restoration, the suffix is generated by calling the controller online.
The frozen R17 one-sided braking rule remains controller policy code (6x for
weak-slew delay 1 and 7x for weak-slew delay 2); it is not a recorded action
suffix.

Before real TSC execution, the mandatory offline gate reconstructed all 18
controllers and recomputed 282 suffix actions exactly, with maximum absolute
action difference 0 and zero new TSC processes.

## 7. Error classification

### 7.1 Runtime/environment errors

Scientific run: 0.

The first launch of the forensic postprocessor omitted the project from
`PYTHONPATH` and stopped immediately with `ModuleNotFoundError`. No run input
was modified and no scientific task ran. Relaunching the identical
SHA-256-identified script with the project path set completed successfully.
This is an audit-tool environment error, not an R2 runtime result.

### 7.2 Packaging/deployment/import errors

The first clean-install command passed a remote `find -name "*.sh"` fragment
through Windows SSH with incorrect quoting. It safely removed only the four
named code directories, then stopped before copying when the malformed
`find` expression failed. Results were untouched. The code tree was restored
immediately from the verified staging tree.

The initial package verifier also treated runtime `__pycache__` files created
by validation as undeclared source. The manifest tree itself was correct.
The verifier was made idempotent by excluding runtime bytecode from the
declared-source check; exact base hashes were checked before patch deployment.

Final staging and installed validation passed. These were deployment/tooling
errors before the certified experiment, not controller or TSC failures.

### 7.3 Raw/snapshot corruption

0. All strict parses, manifest coverage checks, payload sizes, SHA-256 values,
case keys, and source fingerprints passed.

### 7.4 Statistics/reporting errors

The initial offline-only invocation incorrectly wrote
`finished=true/controller_restart_replay_failed` even though the real replay
phase had intentionally not run. This was a reporting-state bug. The phase
state was changed to remain resumable and the online-recomputation flag was
made accurate. Controller semantics, checkpoints, experiment IDs, formal
gate, and physical action semantics did not change.

The final saved summary agrees with independent raw recomputation. Final
scientific-run reporting-error count: 0.

### 7.5 Experimental-design limitations

R2 uses the same two targets, discrete static delay/slew grid, trusted
calibration, R17 controller, and clean digital twin as its source. Its goal is
identity preservation across a genuine controller/process restart. It does
not test robustness to a changed plant or operating context.

The experiment also establishes exactness, not useful tolerance under
uncertainty. The minimum formal margin is too thin to support extrapolation.

### 7.6 Real controller/plant-restart conclusion

Within the finite clean matrix, a fresh TSC process and a fresh controller
process reconstructed from causal checkpoint state reproduce the selected
R17 source suffix exactly in actions, visible state, and full wire-current
state. The immutable formal contract is preserved 18/18.

This is a real same-source controller-state restart result. It is not a
hidden-history or robustness result.
